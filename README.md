# 2026星火杯校赛项目：便携闹钟

---

- **平台**：使用stm32f103，hal库裸机编程，keil编写写入。
- **功能**：
  - 查看时间
  - 设定定时
  - 预定闹钟
    
 ### 欢迎使用这款多功能定时闹钟系统。本产品能够帮助您轻松管理多个定时任务和闹钟提醒。下面将为您详细介绍设备的使用方法。

 ---
 
 - 设备正面可以清晰显示四行文字内容，当您首次启动设备时，屏幕会显示主菜单界面。分别是定时功能、闹钟设定功能和说明功能。屏幕底部还会实时显示当前的时间，您可以通过按键一和按键三在三个选项之间移动，选中的选项会以动画效果高亮显示。当您找到想要进入的功能后，按下按键五即可进入。
 - 如果您选择了定时功能，就会进入定时器列表界面，第一行是一个返回箭头，用于返回主菜单。下面三行分别对应定时器一、定时器二和定时器三。每个定时器后面都会显示当前设定的时间，如果某个定时器已经开启，时间后面会显示一个星号作为标记。
  - 当您选择一个定时器并按确认后，就会进入时间设置界面。您可以使用按键一和按键三在返回箭头、小时、分钟、秒、确定、取消这六个选项之间循环选择。当您选中小时、分钟或秒时，可以按按键五进入数值调节模式。在调节模式下，对应数字下方会出现一条横线，此时按键一可以让数值减小，按键三可以让数值增大，再次按按键五确认修改并返回设置界面。当您调整好时间后，选中确定并按按键五即可保存设置并开启这个定时器，选中取消则放弃修改并返回。
  - 说明功能是一个简单的信息展示界面，进入后会显示系统信息和开发者提供的仓库网址。这个界面目前主要用于展示信息，您按任意按键即可返回主菜单。未来可能会在这个功能中添加更多系统状态和帮助信息。
 -  如果您在使用过程中遇到任何问题，可以尝试按下设备的重置按钮进行重启。重启后，所有设置都会保留，时间也会继续从断电前的状态开始运行。如果时间显示不准确，您需要通过编程接口重新设置RTC时间，这通常由开发者在烧录程序时完成。
